# План змін і контракт джерел

База: edf48902cb9dbecb52bfadb179690c47aafafb00.

## Виявлено й виправлено

1. Фільтри були лише в drawer. Винесено на карту, синхронізовано обидва набори кнопок та aria-pressed.
2. Маркер БпЛА приховував ракети. Тепер показуються обидві категорії без кількості цілей.
3. Статус міг залишатися «Онлайн» після старіння відповіді. Кожні 15 с перевіряється вік, після 120 с відображається застарілість; невідомий формат не перетворюється на порожній список тривог.
4. Швидке перемикання областей/районів могло відобразити попередній запит. Додано перевірку номера запиту. Паралельні fetchAlerts об'єднуються на рівні UI.
5. Закритий drawer залишав доступні клавіатурою елементи. Додано inert, перенесення фокуса та цикл Tab.
6. Вигадані маршрути прибрано. Контур повідомлення каналу означає тільки названу область.
7. Локальний сервер використовує ті самі API handlers, що й Vercel. Оновлено версію PWA-кешу.

| Можливість | alerts.in.ua | Реалізація |

## Канали: вбудований адаптер публічних сторінок

`lib/channel-sources.js` містить 17 наданих користувачем каналів і два офіційні джерела: `kyivoda` та `kyivcityofficial`. Адреси `chyste_nebo` і `chyste_neboo` збережені окремо. Офіційність додаткових каналів не припускається; для ОВА/КМДА збережено посилання на державні сайти, що їх рекомендують.

За замовчуванням `/api/notices` читає публічні сторінки `https://t.me/s/<channel>`. Секрет Telegram або особистий акаунт не потрібний. Це адаптер HTML-прев'ю, не гарантований Telegram API: зміни розмітки, закриття перегляду, блокування чи відсутність доступу показуються як «Недоступний». Ніякого обходу обмежень немає.

- Вибірково розпізнаються явні регіональні оголошення повітряної тривоги й відбою з однією однозначно вказаною областю або містом Київ. Назви дрібніших населених пунктів не геокодуються. Неоднозначні записи, переслані повідомлення та повідомлення без часу пропускаються.
- Сирий текст не надходить до браузера: показується стандартне цивільне попередження, час і посилання на публікацію. Немає підрахунку цілей чи реконструкції їх руху. Повноту автоматичного розпізнавання не гарантуємо; пропущена публікація не означає безпеки.
- Попередження має строк 30 хвилин від часу публікації. Це строк відображення повідомлення, не тривалість офіційної тривоги. Новіший розпізнаний відбій прибирає попередження того самого каналу для того самого регіону. Наступне читання сторінки також враховує редагування/видалення серед доступних останніх повідомлень.
- Джерела завантажуються з паралельністю 5, тайм-аутом 4 с і межею 1,5 МБ на сторінку. Кеш у пам'яті — 60 с, CDN — 30 с. Це не спільний глобальний ліміт усіх serverless-інстансів. Часткова недоступність каналів не блокує решту.
- `CHANNEL_NOTICES_MODE=off` вимикає шар. `CHANNEL_ALLOWLIST` необов'язково обмежує вбудований перелік. `CHANNEL_NOTICES_URL` перемикає endpoint на раніше реалізований зовнішній HTTPS JSON-адаптер; для нього allowlist обов'язковий.

У вкладці «Канали» кожне джерело має маркер «Офіційне джерело» або «Додатковий канал» і результат перевірки доступності. Доступність не підтверджує достовірності. Власні попередження каналів не змінюють офіційного статусу alerts.in.ua.

Перевірка у поточному середовищі: вебпошук відкрив публічні сторінки частини каналів, але вихідний HTTP-запит із середовища виконання отримав сторінку `Site Unavailable` замість Telegram-прев'ю. Живе читання на Vercel потребує перевірки після деплою; не вважати всі 19 джерел перевіреними або доступними наперед.

### Необов'язковий зовнішній адаптер

JSON адаптера:

```json
{"notices":[{"source":"channel_name","region":"Київська область","summary":"Регіональне попередження: перевірте офіційні сповіщення.","url":"https://t.me/channel_name/123","publishedAt":"2026-11-02T10:00:00Z","expiresAt":"2026-11-02T11:00:00Z"}]}
```

Область має відповідати наявному переліку. Посилання тільки HTTPS t.me/<дозволений канал>/<номер>. Запис із майбутньою датою, минулим строком або строком понад 6 год відхиляється. Дублікати видаляються. Додаткові координати та маршрути не передаються браузеру. Адаптер має задавати коротший строк відповідно до повідомлення; 6 год — лише верхня межа валідації. На помилку джерела шар очищується. Запити мають тайм-аут, ліміт 256 КБ та 500 вхідних записів. Кеш у пам'яті 45 с, не гарантує спільний ліміт між serverless-інстансами.

## Деплой і перевірка

Node 22; npm test є buildCommand. Нових залежностей немає. Після merge у підключену гілку Vercel використовує поточний vercel.json. ALERTS_API_TOKEN залишається лише на сервері. Перевірити preview на мобільному й desktop, мережевий збій, області/райони, БпЛА+ракети та клавіатурну навігацію. Живий API потребує токена; без токена очікується 503, а не нуль активних тривог.
