# MAPA UA

PWA для відображення регіональних повітряних тривог України на основі alerts.in.ua.

## Запуск

Node.js 20+. Встановіть секретну змінну середовища `ALERTS_TOKEN` і виконайте `npm start`. Порт задається `PORT` (типово 3000).

Для публічного запуску потрібен Node.js хостинг з HTTPS. GitHub Pages не запускає сервер і не може безпечно зберігати API-токен.

Це не радар БпЛА. Орієнтуйтеся на офіційні сповіщення.
