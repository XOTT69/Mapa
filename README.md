# MAPA UA · карта повітряних тривог

PWA з картою адміністративних меж областей України, пошуком, фільтрами загроз, вибраними областями, світлою/темною темою, регіональною деталізацією, автооновленням та адаптивним інтерфейсом.

## Інтеграція

- Статуси: [alerts.in.ua API](https://devs.alerts.in.ua/).
- Географія: [darmat1/ukraine-geo-data](https://github.com/darmat1/ukraine-geo-data) (GeoJSON, завантаження через jsDelivr).
- Карта: Leaflet, OpenStreetMap/CARTO.

## Vercel

Кореневий каталог репозиторію, Framework Preset: Other. Серверна функція `api/alerts.js` використовує **ALERTS_API_TOKEN** з Environment Variables. Production і Preview конфігуруються окремо. Відкритий endpoint: `/api/alerts`. Токен не записуйте в репозиторій.

Після коміту Vercel запускає деплой, якщо GitHub integration активна. Для локального Node.js запуску: `npm start`.

## Обмеження

Підсвічування всієї області означає наявність відповідного повідомлення в області, а не загрозу на всій її площі. Деякі тривоги стосуються лише районів або громад. **Жодних точних координат чи траєкторій повітряних цілей не показуємо.** Відсутність відмітки не означає відсутність небезпеки. Для особистої безпеки використовуйте офіційні сповіщення та укриття.


## Демонстраційний шар БпЛА

Кнопка «Демо БпЛА» вмикає анімацію трьох **вигаданих** маршрутів із фіолетовими позначками «ДЕМО» та регулятором швидкості. Ці маршрути й кількість маркерів є фіксованою UI-демонстрацією; вони не походять з Telegram, інших каналів чи даних alerts.in.ua та ніколи не повинні використовуватися для оцінки реальної обстановки.

## Надійність географічного шару

Контури областей завантажуються з GeoJSON з резервним джерелом. Якщо обидва джерела недоступні, на карті видно повідомлення та запасні позначки областей. Щоб оновити вже встановлений PWA, застосунок використовує кеш `mapa-ui-v4`.
