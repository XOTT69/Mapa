# MAPA UA 2.1 · Онлайн-мапа тривог

Адаптивний PWA із повноекранною темно-синьою картою України, даними [alerts.in.ua](https://devs.alerts.in.ua/) та географічними межами областей і районів.

## Що реалізовано

- Картографічний головний екран; панель інформації відкривається кнопкою. На мобільному — нижня панель.
- 25 областей і 136 районів із локальних GeoJSON-файлів та інтерактивним підсвічуванням.
- Повна тривога (червона), часткова або попередня (жовта), інші загрози (бузкова), нейтральний колір за відсутності записів API.
- Живі таймери від `started_at`, повні дати початку та перелік активних повідомлень.
- Окремі підказки про **регіональні загрози** БпЛА й ракетами на умовних центрах областей (не цілі!).
- Фільтрація за типом загрози, пошук районів, обране в localStorage.
- Окремий шар регіональних повідомлень із визначених каналів через JSON-адаптер, без координат чи траєкторій. Налаштування: [план і контракт](docs/CHANGE_PLAN.md).
- Автооновлення кожні 45 секунд, захист від застарілих даних, PWA-кеш контурів.

## Запуск

Node.js 22. Підготуйте `ALERTS_API_TOKEN` у змінних оточення сервера, `npm start` для локального Node.js-сервера (файл `server.js`).
Для Vercel проєкт має preset **Other**, `vercel.json` задає `npm test` та папку `public`. Vercel API function — `api/alerts.js`, endpoint `/api/alerts`. Токен зберігати **тільки** як Secret Environment Variable (Production/Preview); не комітити й не передавати у браузер.

Перевірка: `npm test`. Тести покривають адміністративні межі, таймери, категорії загроз і розрізнення повного/часткового охоплення тривог.

## Джерела

- [alerts.in.ua](https://devs.alerts.in.ua/) — активні регіональні повідомлення, `started_at`, `location_type`, `location_oblast`, `location_raion`, `alert_level`, `threats`.
- [darmat1/ukraine-geo-data](https://github.com/darmat1/ukraine-geo-data) — GeoJSON областей.
- [Astaryon/UA_geojson](https://github.com/Astaryon/UA_geojson) — 136 районів відповідно до реформи 2020 року, CC BY 4.0; контури спрощено для вебу. Окремі назви з 2020 року могли змінитися.

## Критичні застереження

**MAPA UA — інформаційна карта, не військовий радар.** Позначка БпЛА/ракета означає, що в області є повідомлення про категорію загрози. Вона **не** відображає координат, кількості або траєкторії повітряних цілей. Вигадану демонстрацію маршрутів прибрано з основного інтерфейсу.

Дані можуть затримуватися, бути неповними або відсутніми. Нейтральне забарвлення **не означає безпеку**. Користуйтеся офіційними оповіщеннями та укриттями.

## Надійність

PWA має SVG-іконку та кеш офлайн-геометрії. Серверна функція Vercel використовує короткий CDN-кеш успішних відповідей (20 секунд із фоновим перевірянням), щоб не надсилати окремий запит до alerts.in.ua для кожного перегляду. У разі недоступності API відображається помилка або позначка застарілих даних.

## Оновлення інтерфейсу

Компактний стан джерела, кількість відфільтрованих повідомлень, легенда і фільтри доступні на карті. Пунктирний фіолетовий контур — область, згадана в повідомленні каналу; він не змінює офіційний статус. БпЛА й ракетні загрози можуть відображатися одночасно. Через 2 хвилини без свіжих даних карта позначається як застаріла.

Вбудований адаптер читає публічні Telegram-прев’ю 17 каналів, наданих власником, та двох офіційних джерел — Київської ОВА й КМДА. У вкладці «Канали» показується доступність кожного джерела. Прев’ю можуть бути недоступними; це не гарантований API. Живе отримання всіх джерел потребує перевірки на Vercel. `CHANNEL_NOTICES_MODE=off` вимикає читання. Зовнішній HTTPS JSON-адаптер можна задати через `CHANNEL_NOTICES_URL`. `CHANNEL_ALLOWLIST` обмежує походження посилань, але не доводить достовірність повідомлення: адаптер має отримувати й перевіряти їх у визначених джерелах. Текст повідомлень виводиться як текст, а не HTML. Контракт та етапи інтеграції наведено в `docs/CHANGE_PLAN.md`.
