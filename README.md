# MAPA UA

Інтерактивна PWA-мапа регіональних повітряних тривог України, дані [alerts.in.ua](https://devs.alerts.in.ua/).

## Функції

- Темна карта України (Leaflet, OpenStreetMap/CARTO) з умовними центрами областей.
- Категорії загроз, активні повідомлення, інтерактивні регіони.
- Автооновлення кожні 45 секунд і мобільний інтерфейс.
- Серверний кеш і API-проксі; токен не передається браузеру.
- PWA та service worker.

## Запуск та деплой

Потрібен Node.js 20+. Додайте змінну оточення `ALERTS_API_TOKEN` з API токеном alerts.in.ua у секрети серверного хостингу та запустіть `npm start`. Порт задається змінною `PORT`, типово 3000.

Для Vercel використовується серверна функція `api/alerts.js` і вже налаштована змінна `ALERTS_API_TOKEN`. Увімкніть автоматичний деплой GitHub-репозиторію у Vercel. Ніколи не комітьте токен.

## Важливо

Це регіональна мапа статусів, а НЕ радар БпЛА. Маркери показують умовні географічні центри областей, не місця загроз. Затримки та пропуски даних можливі. Орієнтуйтеся на офіційні повідомлення ДСНС/повітряних сил.
