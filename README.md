# MAPA UA 2.3 · Онлайн-мапа тривог

Адаптивний PWA із повноекранною темно-синьою картою України, даними [alerts.in.ua](https://devs.alerts.in.ua/) та географічними межами областей і районів.

## Що реалізовано

- Картографічний головний екран; панель інформації відкривається кнопкою. На мобільному — нижня панель.
- 25 областей і 136 районів із локальних GeoJSON-файлів та інтерактивним підсвічуванням.
- Повна тривога (червона), часткова або попередня (жовта), інші загрози (бузкова), нейтральний колір за відсутності записів API.
- Живі таймери від `started_at`, повні дати початку та перелік активних повідомлень.
- Окремі підказки про **регіональні загрози** БпЛА й ракетами на умовних центрах областей (не цілі!).
- Фільтрація за типом загрози, пошук районів, обране в localStorage.
- Окремий шар регіональних повідомлень із визначених каналів через JSON-адаптер, без координат чи траєкторій. Налаштування: [план і контракт](docs/CHANGE_PLAN.md).
- Автооновлення кожні 45 секунд, захист від застарілих даних, PWA-кеш контурів.

## Запуск

Node.js 22. Підготуйте `ALERTS_API_TOKEN` у змінних оточення сервера, `npm start` для локального Node.js-сервера (файл `server.js`).
Для Vercel проєкт має preset **Other**, `vercel.json` задає `npm test` та папку `public`. Vercel API function — `api/alerts.js`, endpoint `/api/alerts`. Токен зберігати **тільки** як Secret Environment Variable (Production/Preview); не комітити й не передавати у браузер.

Перевірка: `npm test`. Тести покривають адміністративні межі, таймери, категорії загроз і розрізнення повного/часткового охоплення тривог.

## Джерела

- [alerts.in.ua](https://devs.alerts.in.ua/) — активні регіональні повідомлення, `started_at`, `location_type`, `location_oblast`, `location_raion`, `alert_level`, `threats`.
- [darmat1/ukraine-geo-data](https://github.com/darmat1/ukraine-geo-data) — GeoJSON областей.
- [Astaryon/UA_geojson](https://github.com/Astaryon/UA_geojson) — 136 районів відповідно до реформи 2020 року, CC BY 4.0; контури спрощено для вебу. Окремі назви з 2020 року могли змінитися.

## Критичні застереження

**MAPA UA — інформаційна карта, не військовий радар.** Позначка БпЛА/ракета означає, що в області є повідомлення про категорію загрози й сама по собі не відображає координат чи траєкторій. Окремий шар «Шахеди» (`/api/threats`) показує **орієнтовні** маршрути за текстами публічних каналів: позиція — центр названого міста/області, стрілка — напрямок за текстом, число — кількість, якщо вона вказана. Це не радарні дані; вони можуть бути неточними, застарілими чи хибними. Вигадану демонстрацію маршрутів прибрано.

Дані можуть затримуватися, бути неповними або відсутніми. Нейтральне забарвлення **не означає безпеку**. Користуйтеся офіційними оповіщеннями та укриттями.

## Надійність

PWA має SVG-іконку та кеш офлайн-геометрії. Серверна функція Vercel використовує короткий CDN-кеш успішних відповідей (20 секунд із фоновим перевірянням), щоб не надсилати окремий запит до alerts.in.ua для кожного перегляду. У разі недоступності API відображається помилка або позначка застарілих даних.

## Оновлення інтерфейсу

Компактний стан джерела, кількість відфільтрованих повідомлень, легенда і фільтри доступні на карті. Пунктирний фіолетовий контур — область, згадана в повідомленні каналу; він не змінює офіційний статус. БпЛА й ракетні загрози можуть відображатися одночасно. Через 2 хвилини без свіжих даних карта позначається як застаріла.

Вбудований адаптер читає публічні Telegram-прев’ю 17 каналів, наданих власником, та двох офіційних джерел — Київської ОВА й КМДА. У вкладці «Канали» показується доступність кожного джерела. Прев’ю можуть бути недоступними; це не гарантований API. Живе отримання всіх джерел потребує перевірки на Vercel. `CHANNEL_NOTICES_MODE=off` вимикає читання. Зовнішній HTTPS JSON-адаптер можна задати через `CHANNEL_NOTICES_URL`. `CHANNEL_ALLOWLIST` обмежує походження посилань, але не доводить достовірність повідомлення: адаптер має отримувати й перевіряти їх у визначених джерелах. Текст повідомлень виводиться як текст, а не HTML. Контракт та етапи інтеграції наведено в `docs/CHANGE_PLAN.md`.

## Карта 2.2

Графітова палітра, компактні панелі й SVG-силуети ракети, БпЛА, авіабомби, авіації та обстрілу. Значки позначають регіональні категорії, а їхня орієнтація не означає курс. Якщо тип невідомий, показується значок тривоги. На районному шарі детальні значки з'являються після наближення. На загальному масштабі вони згруповані за областями. Усі типи загроз показуються разом. Перемикач типу незалежно приховує або показує лише відповідні значки; кольори тривог, таймери, кількість і перелік повідомлень завжди враховують усі активні дані. «Усі» повертає всі значки.

Виправлено огляд України на вузьких екранах: minZoom 3, проміжні масштаби та відступи під панелі. Підписи не накладаються один на одного; таймери довгих тривог на карті стискаються до днів, повний час доступний у картці. Київ і Севастополь доступні окремо в пошуку регіонів.

Leaflet 1.9.4 поставляється локально в public/vendor/leaflet із BSD-ліцензією. Основна карта не потребує CDN чи тайлів; додаткова підкладка потребує мережі. PWA кешує бібліотеку й SVG-модуль. При першому збої API показується явне повідомлення та повторна спроба; при втраті зв'язку збережені дані позначаються застарілими.

## Мої місця, теми й сповіщення 2.3

- Власні назви для областей і районів: Дім, Робота та інші. Додати через картку регіону, переглянути — «Інформація → Мої місця». Кількість не обмежується підпискою; браузерне сховище має власну квоту. Повторна назва оновлює регіон наявного місця.
- Темна, світла й системна тема: «Інформація → ⚙ Налаштування».
- Звук і необов'язкові системні сповіщення для збережених місць. Лише переходи між відсутнім і наявним повідомленням про повітряну тривогу у свіжій відповіді API. Перша відповідь є базовим станом без сигналу; застарілі відповіді та помилки не означають відбою. Оновлення кешу з тим самим часом не повторює сигнал.
- Ця версія перевіряє дані, поки карта відкрита й активна. Після закриття або призупинення сторінки сповіщень немає: серверний Web Push не реалізований. Для системного повідомлення потрібні HTTPS, підтримка браузера, встановлена PWA на iPhone та дозвіл користувача. Дозвіл запитується тільки перемикачем. Звук після перезапуску браузер може вимагати повторно активувати кнопкою тесту.
- Місця й налаштування зберігаються лише у localStorage. Це адміністративні території без точної домашньої адреси. Заблоковане сховище не зупиняє карту; інтерфейс повідомляє, коли зміни не вдалося зберегти.

Не реалізовано точне (радарне) відстеження цілей, графіки висоти, «повтор ночі», Live Activities, CarPlay або watchOS-застосунок.

## Шахеди (орієнтовно)

`lib/threats.js` розбирає тексти публічних Telegram-каналів (`t.me/s/<канал>`): кількість, звідки, де зараз і куди (словник ~60 міст). `api/threats.js` віддає треки за останні `THREAT_TTL_MIN` хвилин (за замовчуванням 40); канали — `THREAT_CHANNELS` або додаткові канали з `lib/channel-sources.js`. `public/threats-layer.js` малює стрілки напрямку, пунктир до цілі та число; кнопка «Шахеди» на панелі шарів. Пересланi повідомлення, питання й тексти зі словами «фейк», «нібито» тощо ігноруються. Підкладка карти (CARTO/OSM) увімкнена за замовчуванням, кнопка «Підкладка» вимикає її.
